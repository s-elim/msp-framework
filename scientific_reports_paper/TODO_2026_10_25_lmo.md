# LM-O occlusion check (pre-declared 2026-10-25 06:05 KST, before any LM-O number)

Motivation: Selim asked for whole-scene, multi-object figures; LINEMOD annotates one object per
frame, LM-O (BOP lmo test_bop19: 200 frames of the benchvise sequence, 8 objects annotated) gives
multi-object frames with heavy occlusion. The same frames support a transfer check that nothing
was tuned on.

Protocol (fixed now): every annotated instance with visib_fract >= 0.1 (the BOP rule) of the 200
frames. Observation, proposals (16, observation-only), hidden physics prior, gripper and
simulator exactly as LM-Grasp (`build_lm_grasp.py` logic, seeds [0, obj, im]); outcomes simulated
at the LM-O annotated pose. FoundationPose with the same weights and settings (5 iterations, GT
visible mask). Planners: point estimate (4 physics draws), U1 posterior (16 x 4, residual bank =
LM-Grasp TRAIN split only, k = 64, no LM-O data), annotated pose (4 draws). Metrics: top-1 success,
within-scene AUC, Sel@25%, paired bootstrap U1 - point. Reported as a transfer check in the paper
whatever the outcome; no parameter is changed after seeing it.

Addendum (06:20 KST, before any LM-O number): the simulator always stands the object upright on
the table (`LinemodGraspSim.rest_pose`), which LM-Grasp verified for LINEMOD (median 0.6-1.4 deg,
`results/sr/lm_upright.json`). LM-O objects may lie tilted. Reported per instance: angle between
the model +z axis at the annotated pose and the fitted table normal; secondary subset = instances
within 15 deg (`upright`), primary = all instances.

## Result (07:12 KST; Slurm 2054 FoundationPose, 2055 planners; results/sr/lmo/lmo_metrics.json)

1,474 instances (visib >= 0.1) in 200 frames; base rate 0.228, oracle 0.805; 55.8 % upright (<= 15 deg).

Reading: the posterior transfers (66 % of the point-to-annotated gap recovered, Sel@25% close to the
annotated pose) but, unlike on LM-Grasp, does not close the gap under heavy occlusion; the residual
bank comes from LINEMOD frames with mild occlusion. Reported as such in the manuscript.
